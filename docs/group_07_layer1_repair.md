## 0. `vii_morph` stores a pick number, so the safe operations are fixed

`vii_morph` stores a sequential pick number 1–112, and `vii_code` translates it back to the ICD-O
code through a nested `if` chain (`REDCap Registry/docs/data-dictionary/Diagnosis.md`, § `vii_morph`,
§ `vii_code`). The table below was generated by reading the option file in order with
`build/build_database.py`'s own parser, and its pick numbers match the live `vii_code` formula
pick for pick (1 → `8970`, 2 → `8975`, 3 → `8963`, 4 → `8991`, … 112 → `8005`).

The three safe operations are the ones `docs/TODO.md` §7 sets for every group:

- **Relabel in place** — change the label text, keep the pick number and its `vii_code` line.
- **Retire in place** — prefix the label `[RETIRED]` and make `vii_code` return blank for that pick.
  Never delete a pick: deleting one renumbers every pick after it, and every stored record after it
  silently changes meaning with nothing that trips a data-quality rule.
- **Append at the end** — new picks start at 113.

`vii_extended` and `vii_subgroup` are calculated from `vii_morph`. Appended picks need a `vii_subgroup`
line (all seven are VIIb); `vii_extended` populates only for VIIa1–VIIa3 and needs none.

## 3. The findings that need more than a relabel

**Pick 2, `8975` Calcifying nested epithelial stromal tumor.** ICD-O-3.2 carries the code at `/1`
only, as "Calcifying nested stromal-epithelial tumor" — the word order differs too. ICCC-3 Group VII
admits behaviour 3. The lookup tool emits a behaviour exclusion for it and refers the case to the
registrar. Whether the registry keeps a Group VII pick for it is the registrar's decision (Group 7 build
contract §11.2), so this package does not retire it.

**Picks 88 and 89, `8504`.** Both labels are `8504/2` synonyms ("Noninfiltrating intracystic
carcinoma", "Intracystic carcinoma, NOS"). The behaviour-3 entity on the code, "Encapsulated papillary
carcinoma with invasion", has no pick. **Retire both and append the `/3` term as pick 120.** The first
draft of this package relabelled pick 89 to the `/3` term; that would have turned every record already
stored on pick 89 from an in situ lesion into an invasive carcinoma, the hazard §0 exists to prevent.
A relabel is safe only when the old and new labels name the same disease at the same behaviour.

**Pick 47, `8158`.** "Endocrine tumor, functioning, NOS" is a Related term under `8158/3` that
ICD-O-3.2 marks obsolete; the preferred term is "ACTH-producing tumor". The pasted note in the label
says the term is of uncertain behaviour; ICD-O-3.2 has no `8158/1` row.

**Pick 102, `8162`.** "Klatskin tumor" is a synonym ICD-O-3.2 marks obsolete; the preferred term is
"Perihilar cholangiocarcinoma".

**Pick 1, `8970`.** "Hepatoblastoma" is not an ICD-O-3.2 term at any level; the term is
"Hepatoblastoma, NOS".

**Seven labels carry pasted transcription notes** (picks 2, 47, 52, 71, 93, 99 and 103, whose note
is about `8C18.0`). Every relabel or retire removes the note with the old text.

**Pick 59, `8240` "Carcinoid tumor of uncertain malignant potential"** is not an ICD-O-3.2 term at any
behaviour. Retire it; pick 60 relabelled to "Neuroendocrine tumor, NOS" carries the code.

**Behaviour 2, 6 and 9 picks.** Twenty picks carry an in situ (`/2`), metastatic (`/6`) or
uncertain-primary (`/9`) reading of a code — the nineteen of contract §2D plus pick 88 — and in every
case but `8504` the `/3` option sits beside it. ICCC-3 Group VII declares
behaviour 3 only. Each is a pick a clerk can take with the right four digits and the wrong label. This
package retires them; if the registrar wants in situ hepatic lesions recorded, they need a home outside
Group VII, not a pick inside it.

## 4. Pre-flight — before changing anything

1. Export `vii_morph` counts by pick. Any record on a pick this package retires needs review before the
   retire, because retiring blanks its `vii_code`. Review relabelled picks too: each relabel here keeps the
   disease and behaviour, but a record entered against the old label should still read correctly against the
   new one.
2. Confirm pick 103's stored records are hepatocellular carcinoma: the pasted note mentions `8C18.0`, a
   topography-like string, and a record entered against it before the note was noticed is worth a look.
3. Apply relabels and appends together, retires after the review in step 1.

## 5. What the lookup tool already does

- `morphology_name` is the ICD-O-3.2 preferred term at behaviour 3 for every entry, checked by
  `check_icdo32_round_trip()`. The REDCap strings appear as aliases, so the output block lists both.
- The output block shows "The REDCap label for this code is out of date" on the ten drifted codes and
  "Not yet a REDCap option" on the seven codes this package appends.
- No branch emits `8975`, `8148`, `8202`, `8264`, `8561` or `9013` (`check_group7_absent_codes`).
