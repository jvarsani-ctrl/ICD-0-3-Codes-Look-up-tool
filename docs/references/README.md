# `docs/references/` — papers the build depends on

Papers held here are **cross-cutting**: they govern more than one ICCC-3 group, so they belong
to the tool rather than to a `Group N Papers/` folder. Per-group classification papers stay in
the vault's `Group N Papers/`; the index of which paper serves which group is
[`../group_baseline_documents.md`](../group_baseline_documents.md).

Only redistributable papers go here. This repository deploys as GitHub Pages and serves its own
files, so anything committed is published.
